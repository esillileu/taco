# Glossary

- TACO: Task Context Orchestrator.
- Task: Single work unit document used as execution SSOT.
- Context Pack: Deterministically assembled task context payload.
- Write Target: Precise path and locator for recording results.
- ADR: Architecture Decision Record documenting why a decision was made.
- SSOT: Single Source of Truth.
- Deterministic Extraction: Heading/anchor based extraction without LLM summarization.
