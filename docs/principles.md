# Principles

## Engineering Principles

- Prefer clarity over cleverness.
- Keep decisions traceable to documented intent.
- Optimize for maintainability and explicit ownership.

## Documentation Principles

- Single source of truth for structure (`doc-map`).
- Consistent headings and path conventions.
- Explicit cross-linking between related artifacts.

## Delivery Principles

- Small, reviewable increments.
- Validate changes with lightweight checks.
- Keep backlog and status visible in task/todo docs.
