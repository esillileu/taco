# Git Principles

> Priority rules that all contributors and agents must follow.

## References

- [Git Rules Index](./index.md) - entry point for git conventions
- [Documentation Guide](../doc/index.md) - operational writing rules
- [Branch Rules](./02-branches.md) - branch execution policy

## Rules

- Protect shared branches first.
- Use PR-based integration.
- Start work from issues.
- Keep commits traceable and meaningful.
- Never violate a higher-priority rule for lower-priority convenience.
