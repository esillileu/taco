# Glossary

> 프로젝트 상태를 일관되게 추적하기 위한 핵심 용어를 정의한다.

## References

- [Intent](./intent.md) - 목표와 성공 기준
- [Architecture](./architecture.md) - 시스템 구성 맥락
- [Plan](./plan.md) - 단계 맥락

- `TACO`: Task Context Orchestrator
- `Task`: 단일 작업 단위 실행/추적 문서
- `Context Pack`: task 수행에 필요한 최소 정보 묶음
- `Write Target`: 완료/갱신 기록의 정확한 파일/섹션 위치
- `Deterministic Extraction`: heading/anchor 기반 고정 추출 방식
- `SSOT`: Single Source of Truth
- `Doc Map`: 문서 구조/역할/작성 규칙을 안내하는 기준 문서
- `Implementation Readiness`: 구현 이전 설계/정렬 단계
- `Tool Surface`: MCP에서 노출되는 기능 인터페이스 집합
- `Canonical Tool Naming`: 단수 도메인 + 간결 액션 규칙 (예: `task.pack`, `doc.snippet`)
